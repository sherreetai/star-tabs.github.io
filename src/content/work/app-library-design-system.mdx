outcome: Made theme application ~93% faster, reducing it from 54+ seconds to under 4 seconds and saving an estimated 5–6 hours per designer each year.

  <CaseSection eyebrow="Finding the inconsistencies" title="Audited the existing system" mediaSrc="/images/app-library/audit.svg" layout="centered" divider="none" paddingTop="large">
    <p>I helped audit repeated patterns and inconsistent component states across the apps, identifying where components could be consolidated into shared foundations.</p>
  </CaseSection>

  <CaseSection eyebrow="Building scalable foundations" title="Rebuilt components with Figma Variables" mediaSrc="/images/app-library/rebuild.svg" layout="split">
    <p>I helped rebuild components from atomic foundations using Figma Variables, replacing the slower Tokens Studio workflow with native theming and reducing reliance on third-party tooling.</p>
  </CaseSection>

  <CaseSection eyebrow="Closing the design-to-code gap" title="Aligned design with development" layout="centered">
    <p>I worked with engineering so component and variable logic reflected how the UI was built, helping reduce gaps between Figma and implementation.</p>
  </CaseSection>

  <CaseSection eyebrow="Putting the system into practice" title="Implemented the system in My O2 App" mediaSrc="/images/app-library/components.svg" layout="centered">
    <p>I created the My O2 App master file and was the first to implement the new Figma Variables into a live app design file. This proved the variable structure could work in practice and created a foundation for migrating components away from Tokens Studio.</p>
  </CaseSection>
</CaseDecisionGrid>

<CaseSection eyebrow="Faster by design" title="~93% faster theme application" paddingTop="large" paddingBottom="none">
  <p>Moving to Figma Variables reduced theme application from 54+ seconds to under 4 seconds. Across 7,609 recorded component inserts, this was estimated to save 5–6 hours per designer each year while creating a more scalable cross-brand foundation.</p>
</CaseSection>
